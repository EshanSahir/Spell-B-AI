This Project includes these features:
Interactive Dictation & Pronunciation Engine: Features multi-speed Web Speech API speech synthesis (Standard and 0.6x Slow Dictation), phonetic IPA transcriptions, syllable breakdowns, and letter-by-letter audio spell-outs.
Official Bee Clues & Instant Accuracy Feedback: Provides real-time character-by-character visual alignment for every entered word, highlighting correct letters, missing vowels, or misplaced consonants along with etymological memory hooks.
Gemini AI Word List Generator & Coach: Integrates Gemini 3.6 Flash to generate custom competition word lists based on topic/origin (e.g., French Loanwords, Greek Medical Roots, Scripps Finals) and offers a dedicated AI Champion Coach chat for spelling rules and mnemonic advice.
Difficulty Adjustment Toggles: Seamlessly switches between Beginner, Intermediate, Advanced, and Championship levels across practice dictations and word list collections.
Daily Progress Tracking & Summary Report: Records daily practice activity, streak counters, mastery percentages across difficulty tiers, and provides downloadable summary reports.
Targeted Mistake Bank: Automatically logs missed words into a dedicated error bank for retry drills until mastered.
